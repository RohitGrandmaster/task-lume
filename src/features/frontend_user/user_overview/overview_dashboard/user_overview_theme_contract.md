# Theme Contract: User Overview Dashboard (`user_overview_overview_dashboard`)

## Consumed Design Tokens

### Color Tokens
- `tokens.color.background` — Root background
- `tokens.color.foreground` — Metric labels & titles
- `tokens.color.card` — KPI cards & chart card containers
- `tokens.color.primary` — Primary gold series & progress highlights
- `tokens.color.primarySubtle` — Metric icon circular backdrops
- `tokens.color.chartPrimary` (`#FACC15` / `#EAB308`) — Primary chart bars
- `tokens.color.chartSuccess` (`#4ADE80` / `#16A34A`) — Positive completion metrics
- `tokens.color.chartWarning` (`#FBBF24` / `#F59E0B`) — Medium priority / warning breakdowns
- `tokens.color.chartDanger` (`#F87171` / `#DC2626`) — Overdue / high priority bars
- `tokens.color.chartInfo` (`#60A5FA` / `#2563EB`) — Secondary categories

### Typography & Spacing
- `tokens.typography.kpi` (28/34 bold) — Big stat numbers
- `tokens.typography.labelUppercase` (11/16 bold) — Upper metric titles
- `tokens.space[2]`, `tokens.space[3]`, `tokens.space[4]`, `tokens.space[5]`
- `tokens.radius.lg` (12)
