# Theme Contract: User Voice Memos (`user_voice_voice_memos`)

## Consumed Design Tokens

### Color Tokens
- `tokens.color.background` — Screen background
- `tokens.color.foreground` — Heading & transcript text
- `tokens.color.card` — Transcript preview surface
- `tokens.color.primary` — Mic active button & convert CTA
- `tokens.color.onPrimary` — Mic button icon
- `tokens.color.primarySubtle` — Pulse wave animation backdrop
- `tokens.color.border` — Card outline

### Layout Tokens
- `tokens.layout.minTouchTargetIos` (44) / `minTouchTargetAndroid` (48) via `getMinTouchTarget()`
- `tokens.space[4]`, `tokens.space[6]`, `tokens.radius.full`
