# Theme Contract: User Settings Profile (`user_settings_settings_profile`)

## Consumed Design Tokens

### Color Tokens
- `tokens.color.background` — Screen background
- `tokens.color.foreground` — Setting titles & headings
- `tokens.color.card` — Setting row card container
- `tokens.color.primary` — Switch active track & primary accent icons
- `tokens.color.border` — Row dividers
- `tokens.color.muted` — Setting descriptions & inactive switch color
- `tokens.color.statusDangerText` — Reset data warning

### Layout Tokens
- `tokens.layout.minTouchTargetIos` (44) / `minTouchTargetAndroid` (48) via `getMinTouchTarget()`
- `tokens.space[3]`, `tokens.space[4]`, `tokens.radius.lg`
