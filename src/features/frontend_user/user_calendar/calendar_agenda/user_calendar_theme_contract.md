# Theme Contract: User Calendar Agenda (`user_calendar_calendar_agenda`)

## Consumed Design Tokens

### Color Tokens
- `tokens.color.background` — Screen background
- `tokens.color.foreground` — Month header & task titles
- `tokens.color.card` — Calendar surface & agenda card
- `tokens.color.primary` — Selected date pill & today indicator
- `tokens.color.onPrimary` — Selected date text
- `tokens.color.border` — Day grid divider
- `tokens.color.muted` — Day of week header & secondary timestamps

### Layout Tokens
- `tokens.layout.minTouchTargetIos` (44) / `minTouchTargetAndroid` (48) via `getMinTouchTarget()`
- `tokens.space[3]`, `tokens.space[4]`, `tokens.radius.full`
