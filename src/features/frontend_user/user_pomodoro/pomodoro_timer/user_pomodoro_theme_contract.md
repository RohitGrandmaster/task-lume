# Theme Contract: User Pomodoro Timer (`user_pomodoro_pomodoro_timer`)

## Consumed Design Tokens

### Color Tokens
- `tokens.color.background` — Screen background
- `tokens.color.foreground` — Timer digits & labels
- `tokens.color.card` — Interval chips & controls container
- `tokens.color.primary` — Work focus ring & primary start button
- `tokens.color.onPrimary` — Start button icon/text
- `tokens.color.statusSuccessText` / `statusSuccessBg` — Short break indicator
- `tokens.color.statusWarningText` / `statusWarningBg` — Long break indicator
- `tokens.color.destructive` — Stop / reset button

### Layout Tokens
- `tokens.layout.minTouchTargetIos` (44) / `minTouchTargetAndroid` (48) via `getMinTouchTarget()`
- `tokens.space[3]`, `tokens.space[4]`, `tokens.space[6]`
