# Theme Contract: User Reminders Active (`user_reminders_reminders_active`)

## Consumed Design Tokens

### Color Tokens
- `tokens.color.background` — Screen background
- `tokens.color.foreground` — Reminder titles & headings
- `tokens.color.card` — Reminder item surface
- `tokens.color.primary` — Clock / bell active icon & snooze CTA
- `tokens.color.onPrimary` — Primary button text
- `tokens.color.border` — Card outline
- `tokens.color.muted` — Time & date timestamps

### Layout & Touch Targets
- `tokens.layout.minTouchTargetIos` (44) / `minTouchTargetAndroid` (48) via `getMinTouchTarget()`
- `tokens.space[3]`, `tokens.space[4]`, `tokens.radius.lg`
